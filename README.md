# Website Portofolio Ashabul Kahfi

Website portofolio interaktif, modern, dan premium untuk menampilkan keahlian dan proyek-proyek GitHub.

## Fitur Utama
1. **Desain Sistem Gelap & Neon (Glassmorphism)**: Tampilan visual premium yang futuristik dengan gradien dinamis.
2. **Featured Projects (Proyek Unggulan)**: Menampilkan detail proyek ARKEUS, Warkop Azzahra, MR. WASH, Nol 3 Coffee, dan Game Tetris beserta tautan demo/code.
3. **Live GitHub API integration**: Menarik data seluruh repositori publik dari akun GitHub `tehkotak88` secara otomatis.
4. **Pencarian Repositori Real-time**: Memfilter repositori di sisi klien saat mengetik nama proyek atau bahasa pemrograman.
5. **Formulir Rencana Proyek terintegrasi WhatsApp**: Merangkum formulir kontak menjadi pesan chat WhatsApp otomatis ke nomor Anda.
6. **Desain Responsif**: Optimal untuk mobile, tablet, dan desktop.

## Struktur File
* `index.html` - Struktur utama halaman web (SEO Friendly).
* `style.css` - Desain sistem, layout grid/flexbox, efek blur, hover, dan animasi.
* `app.js` - Logika interaktivitas, integrasi API GitHub, WhatsApp redirect, dan stats count.
* `assets/` - Folder penyimpanan visual mockup proyek.
* `package.json` - File konfigurasi npm untuk menjalankan server lokal.

## Cara Menjalankan Lokal

1. **Prasyarat**: Pastikan Node.js sudah terinstal di komputer Anda.
2. **Buka Terminal**: Arahkan terminal ke direktori folder portofolio ini.
3. **Instalasi Dependencies**:
   ```bash
   npm install
   ```
4. **Jalankan Server Lokal**:
   ```bash
   npm run dev
   ```
5. **Akses Portofolio**: Buka browser dan buka alamat lokal yang ditampilkan di terminal (biasanya `http://localhost:5173`).
